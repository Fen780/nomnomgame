# CHANGELOG

Короткий журнал работы над проектом. Не нужно писать длинный отчёт.

## Рефакторинг: модульная структура + глобальный конфиг

**Что сделал:**

- код разбит на несколько файлов: `gameConfig.ts`, `types.ts`, `items.ts`, `GameScene.ts`, `config.ts`;
- создан глобальный конфиг игры `src/game/gameConfig.ts` — все числа, эмодзи, цвета, тексты и отступы теперь в одном месте; гейм-дизайнер может менять баланс, не заглядывая в игровой код;
- фаза 2 переведена с запуска по времени на запуск по прогрессу (счёту): `phases.phase2ScoreThreshold` в конфиге;
- логика игры не менялась: `pnpm run typecheck` и `pnpm run build` проходят, игра запускается;
- обновлён `README.md` (структура проекта).

## Фаза 2 (ад) + уменьшение сцены

**Что сделал:**

- добавлена фаза 2: при наборе 20 очков начинается «ад» — красный фон, кот превращается в демона, сердца становятся чёрными;
- за 5 очков до порога показывается предупреждение «⚠️ PHASE 2 INCOMING ⚠️», при старте — баннер «🔥 PHASE 2 🔥»;
- в фазе 2 появляются новые предметы: бомба `💣` (−2 жизни) и звезда `⭐` (+3 к счёту);
- сцена уменьшена с 960×640 до 800×500 — играть стало проще.

**Заметка про запуск фазы 2 (видно в git-истории):** перебирал два варианта триггера — по времени (`PHASE_1_DURATION_SECONDS`, сначала 60 с, для теста 20 с) и по прогрессу/счёту (`PHASE_2_SCORE_THRESHOLD` в ветке `feature/phase2-progress`). Остановился на прогрессе: игрок сам управляет темпом — быстрее ловишь еду, быстрее наступает фаза 2.

## Практика / домашняя работа №1

**Что сделал:**

- игра «Hungry Cat»: кот внизу экрана ловит падающую еду (`src/game/GameScene.ts`);
- пойманная еда — +1 к счёту, мусор 🗑️ — минус жизнь, пропущенная еда — минус жизнь;
- всего 10 жизней: 0 жизней = game over (10 пропущенных порций = мгновенный проигрыш);
- сложность растёт со временем: скорость падения увеличивается, интервал спавна уменьшается;
- HUD: счёт, жизни, подсказка управления; экран проигрыша с рестартом по `R` или клику;
- пауза по `Esc`: игра замирает, показывается оверлей «PAUSED», повторное нажатие `Esc` продолжает игру;
- фон игры стал светлее и дружелюбнее (светло-голубой), HUD перекрашен под новый фон;
- обновлены `README.md` и этот `CHANGELOG.md`.
